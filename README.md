# Woman That Leads

Next.js 15 (App Router, TypeScript).

    npm install
    npm run dev      # http://localhost:3000
    npm run build && npm start

- Edit all text, links and photo paths in `lib/content.ts`.
- Put images in `public/images/` and reference them as `/images/your-file.jpg`.
- Colours and layout live in `app/globals.css` (`:root` variables at the top).
- Deploy on Vercel by importing the repo, no config needed.
